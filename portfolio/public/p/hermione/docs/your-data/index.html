Using Hermione

Your data

Everything you make in Hermione is saved on your Mac, in files you can see, copy and back up. Nothing depends on a server or a plan.

#Where it lives

~/Library/Application Support/com.ansarbuilds.hermione/
├── workspace.json        every project, issue, page and setting
├── backups/              one copy a day, the last 14 days
├── attachments/          files attached to issues and pages
└── models/               Hermione AI, if you downloaded it

Every change is saved at once, written to a temporary file first and then swapped in, so a crash or a full disk never leaves half a file. The browser version keeps the same data in the browser's IndexedDB.

Settings → Your data → Data folder moves everything to another folder, a synced one or an external drive, and the app follows it.

#Backups

The first save each day copies the previous day's file into backups/; the newest 14 are kept. Settings → Your data → Backups lists them; Restore replaces the workspace with one (the current state is backed up first, so a restore can itself be undone).

#Undo

⌘Z and ⇧⌘Z undo and redo any change, including the assistant's. ⇧⌘H shows the last 30 changes in words and jumps back to any of them. See Undo history.

#Trash

Deleted issues and pages wait in Settings → Trash for 30 days, then go for good. Restore puts one back where it was, with its comments and history. Delete for good skips the wait.

#Import

Settings → Your data → Import:

From File What comes across
Jira CSV export Issues, types, statuses, priorities, assignees, labels, estimates, due dates, parents
Linear CSV export The same
Trello Board JSON Cards as issues, lists as statuses, labels, members, due dates, checklists
GitHub Issues JSON (gh issue list --json …) Issues, labels, assignees, open or closed
Hermione CSV, or a full JSON export Everything

Statuses are matched by meaning, so "Closed", "Done" and "Resolved" all land in your Done category.

#Export

Settings → Your data → Export:

  • Everything (JSON): the complete workspace, re-importable exactly.
  • Everything as Markdown (zip): pages as nested Markdown files, issues as Markdown files with their fields as frontmatter, and links as [[wiki links]], ready for Obsidian or any Markdown folder.
  • Issues (CSV): for a spreadsheet.
  • A page as Markdown or PDF, from the page itself.

#Reset

Settings → Your data → Reset the sample puts the sample project back as it was. Danger zone removes a project, after asking.
