Using Hermione

Pages

Pages are the handbook beside the work: specs, meeting notes, runbooks, decisions. G then P.

#Writing

The editor is Markdown with a toolbar, so headings, lists, to-dos, tables, quotes, code, links and images all work the way you'd type them.

  • Type / at the start of a line for a menu of blocks: heading, subheading, bulleted, numbered and to-do lists, quote, code block, table, divider, image, diagram and a live issue list.
  • Type @ to mention a person, or an issue key like HER-4 to link it.
  • ⌘B, ⌘I and ⌘K for bold, italic and a link. ⌘↵ saves.
  • Paste or drop a file or image to attach it.
  • A table of contents appears beside long pages.

#Visual editing

Every editor has three tabs: Write (the Markdown), Visual and Preview. Visual shows the page formatted; click a block to edit just that block's Markdown in place, with the toolbar, the / menu and mentions all working.

#Templates

New page offers templates: meeting notes, a decision record, a retrospective, a project brief and a how-to guide. Save as template on any page adds it to the gallery; your own templates show first.

#Diagrams

A code block marked mermaid is drawn as a diagram, in your theme, by Hermione's own parser and layout. Flowcharts and sequence diagrams are drawn; other kinds stay as text. Each diagram also has a written summary for screen readers, and Diagram text shows the source.

```mermaid
flowchart LR
  A[Edit on Mac] --> B{Online?}
  B -->|yes| C[Relay]
  B -->|no| D[Queue locally]
```

#Live issue lists

A line that starts /issues followed by filter words becomes a list of matching issues that stays current:

/issues is:open type:bug label:web

Use it for "open bugs" on a release page, or "my work this week" on a planning page.

#Backlinks

Linked from at the foot of a page lists the issues, pages and comments that mention it.

#History

History keeps every saved version. Pick two to compare them side by side with changes marked, and restore any version (the current one is kept too).

#Comments

Select any text to comment on that passage. Comments on the whole page sit at the bottom. Both support @mentions.

#Organising

  • Drag pages in the tree to reorder them or nest one under another.
  • Labels on pages filter the list; Private makes a page only you can see.
  • Give a page an icon and a cover.

#Export

Export saves a page as a Markdown file, or prints it (Save as PDF in the Mac print dialog). To export every page at once, see Your data.
