Get started

Hermione

Hermione is a project workspace that lives on your Mac. Issues, a kanban board, a backlog, sprints, a roadmap, releases and a handbook of pages, in one window, saved to one file you own. There is no account, no server and no subscription to use it. It is free and open source under Apache-2.0.

Press ⌘J and say what you want, "create a bug for @priya due friday" or "plan the next sprint with 20 points", and Hermione makes the change, shows you the plan first when there's more than one step, and lets you undo it. A small model trained for exactly this job can run on your Mac to understand more; it gets 93% of requests exactly right and never sends your work anywhere.

#Who it's for

  • One person running a real project. A thesis, a side project, a freelance client, a product you're building alone, tracked with the same tools a team would use, without signing up for one.
  • Small teams that want their plan on their own machines. Sync between devices is being built (end-to-end encrypted, through a relay you can host yourself); today each workspace lives on one Mac.
  • Anyone who wants AI help without sending their work to a cloud. The assistant works offline. The optional model runs locally.

#Your first five minutes

  1. Install it and open it. Hermione asks your name, what you do, and how it should look, then opens a sample project called Hermione with a sprint already running, so there is something to click.
  2. Open the board (G then B). Drag a card from To do to In progress. Press ⌘Z to put it back.
  3. Open an issue. Click any card for a side panel, or ⌘-click for the full page. Change the priority, add a comment with an @mention.
  4. Press ⌘J and type create a task: write the launch post, due friday, for me. The issue appears. Press Undo this to take it back.
  5. Press ⌘K and type a word from any issue or page.
  6. When you're ready for your own work, Settings → Your data → Reset the sample, or start a New project from the project card at the top of the sidebar.
