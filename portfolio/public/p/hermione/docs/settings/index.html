Using Hermione

Settings

G then ,. Settings are in three groups: Account (you, your plan, the assistant, the keyboard), Project (this project's setup) and This Mac (your data, sync, privacy, about).

#Appearance

At the bottom of the sidebar, or in Settings → You.

Setting Choices
Theme Light, Dark, or Auto (follows macOS)
Colour Indigo, Violet, Emerald, Ember, Rose, Amber, Graphite, or any colour you pick
Type Inter, Plex or Mono
Text size Small, Normal, Large, Larger
Density Comfortable or Compact
Contrast Normal, High (solid surfaces, stronger text and lines), or follow macOS Increase contrast
Language English or Français (Canada); follows macOS by default

Hermione also follows macOS Reduce motion and Reduce transparency.

#Project

Name, description, icon and colour. The key prefixes every issue and can only change while the project has no issues. Archive project hides it from the switcher; Restore brings it back.

#Workflow

The statuses that become board columns, in order. Each belongs to a category, To do, In progress or Done, which decides what counts as started and finished in progress bars and reports. Rename, reorder, add or remove them; removing one asks where its issues should go.

#Rules

Click Rules on a status to decide:

  • Which statuses an issue can come from. For example, Done only from In review.
  • What it needs before it moves in: an assignee, points, a due date, a description or a time estimate.

A move that breaks a rule is refused with the reason, on the board, in lists and from the assistant alike.

#Automations

Rules that do the busywork. Each has a when and a then:

When Then
An issue is created Set its priority
An issue moves into a status Assign it to someone
Add a label
Move it to a status
Add it to the current sprint
Close its child issues

For example: when an issue moves into Done, close its child issues, or when a bug is created, add it to the current sprint. Rules don't set each other off, and a rule that can't apply to an issue is skipped without blocking the change.

#People

Everyone who can be assigned work or mentioned: a name, a handle for @mentions, and an email if you like. Hermione runs on your Mac, so these are names, not accounts.

#Labels and custom fields

Labels have colours that show on cards; renaming one changes it on every issue. Custom fields add text, number, choice or date fields to every issue's Details panel.

#Recurring issues

Chores that come back: give a summary, how often (every day, every weekday, every week, every two weeks or every month), the first day and an assignee. Each is created on its day, the next time the project is open, due that day.

#Assistant

Which engine answers ⌘J: the built-in one only, Hermione AI (Pro), or your own model server. Also the web settings for Hermione AI + Web, and Recent actions, a log of what the assistant did. See The assistant and Hermione AI models.

#Privacy

Everything that can ever leave this Mac, listed in full: when, where to, and what's sent. Your projects, issues and pages never leave. The assistant never does either, with the built-in engine or Hermione AI. Web answers send only the search words; update checks send only the version, and only when you ask. Here too: the Show in Spotlight switch. Hermione has no account, no analytics and no tracking. See Privacy and security.

#About

The version, the data folder, the bundled llama.cpp runtime, and Copy diagnostics: a short report for bug reports with versions and counts, and none of your project text.
