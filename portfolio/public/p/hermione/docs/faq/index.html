FAQ and troubleshooting

#Questions

Is it really free? Yes. Every feature in the app is free and stays free, and the code is Apache-2.0. Pro adds the one-click trained model, web answers and (soon) sync.

Does it need the internet? No. Everything works offline, including the assistant. The internet is used only for things you ask for: downloading a model, web answers, checking for updates.

Can my team use it? Each workspace lives on one Mac today, and the people in it are names for assigning and mentioning, not accounts. Sync between devices is built and being switched on next.

Is it a Jira clone? It rebuilds familiar shapes (a board, an issue with a Details panel, a page tree) in its own original code, and adds what those tools don't have: a local file you own, an offline assistant, and a model that runs on your Mac. It isn't affiliated with Atlassian.

Where's my data? ~/Library/Application Support/com.ansarbuilds.hermione/, or the folder you chose. See Your data.

Does the AI see my work? Only on your Mac. The built-in engine and Hermione AI both run locally. With web answers on, only the search words leave. See Privacy.

Can I use Hermione AI in other apps? The model is Apache-2.0 on Hugging Face, but it's trained for Hermione's tools and prompt, so it isn't a general assistant.

Is there an iPhone or iPad app? Not yet. It's next, after sync.

#Troubleshooting

"Hermione can't be opened because Apple cannot check it for malicious software." Right-click Hermione in Applications → Open → Open. You only do this once.

"Hermione is damaged and can't be opened." macOS is being strict about a downloaded file. Run this once, then open it again:

xattr -dr com.apple.quarantine /Applications/Hermione.app

The assistant says it didn't catch that. The built-in engine understands plain, common sentences. Try naming the issue key and a verb ("move HER-3 to done"), or set up Hermione AI or your own model in Settings → Assistant for looser language.

"I couldn't reach your model." Your model server isn't running at the address in Settings → Assistant → Your model. Start it (llama-server -m … --jinja --port 8080) and press Test connection.

The model download stopped. Press Resume; it continues where it left off. If it says the download was damaged, it failed its checksum and was deleted; download it again.

Hermione AI is slow. The first request loads the model, which takes a few seconds. After that, answers usually take one to three seconds on Apple silicon. Close other heavy apps on an 8 GB Mac.

Something went wrong after an update. Your data is safe in its folder, with 14 daily backups. Settings → Your data → Backups → Restore goes back to any of them. Then please report it with Settings → About → Copy diagnostics.

I deleted something by mistake. ⌘Z, or ⇧⌘H to go back several changes, or Settings → Trash for up to 30 days.

#Reporting a bug

Open an issue on GitHub with what you did, what happened, and the text from Settings → About → Copy diagnostics (it contains no project text).
