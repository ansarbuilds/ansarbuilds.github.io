Get started

Install

Hermione runs on Apple silicon Macs (M1 or later) with macOS 11 Big Sur or later. Intel Macs can build it from source. A Windows build is produced in CI but not yet published.

#On a Mac

  1. Download Hermione_0.3.0_aarch64.dmg (about 20 MB) from the latest release.

  2. Open the DMG and drag Hermione into Applications.

  3. The first time, right-click Hermione → Open, then Open again.

    The app is not yet signed with an Apple Developer ID, so macOS asks before opening it the first time. After that it opens like any other app. If macOS says it "is damaged and can't be opened", that is the same check being stricter about a downloaded file; run this once and open it again:

    xattr -dr com.apple.quarantine /Applications/Hermione.app

  4. Hermione asks your name, what you do and how it should look, then opens.

#Where your data goes

Everything is saved to one folder:

~/Library/Application Support/com.ansarbuilds.hermione/

You can move it anywhere, a synced folder for example, in Settings → Your data → Data folder. More in Your data.

#Updating

Choose Hermione → Check for Updates (or Settings → About). Hermione asks GitHub for the latest release, sending only its version number, and tells you if there's a newer one. Download it and drag it over the old copy; your data is kept. Every version reads every older data format; this is tested on each change with saved data from every past version.

After an update, What's new shows once with the changes.

#Removing it

Drag Hermione from Applications to the Trash. Your data stays in its folder until you delete that too:

rm -rf ~/Library/Application\ Support/com.ansarbuilds.hermione

If you downloaded Hermione AI, the model files are in the same folder (about 1.3 GB each).

#Running from source

For development, or to use Hermione in a browser tab.

git clone https://github.com/ansarbuilds/Hermione.git
cd Hermione
pnpm install
pnpm dev          # http://localhost:5173, data kept in this browser
pnpm desktop      # the Mac app, with hot reload
pnpm desktop:build  # a packaged .app and .dmg

You need Node 20.9 or later, pnpm 12, and, for the desktop app, Rust (stable) and the Xcode command line tools. The desktop build downloads a pinned llama.cpp release once and bundles its llama-server; set HERMIONE_SKIP_LLAMA=1 to build without it.

The browser version is the same interface with the data in IndexedDB. Use Settings → Your data → Export → Everything (JSON) to keep a copy, and Restore from an export to move it into the Mac app.

#System requirements

Minimum Recommended
macOS 11 Big Sur 14 Sonoma or later
Chip Apple silicon (the published build is arm64; Intel Macs can build from source) M1 or later
Memory 4 GB 8 GB or more for Hermione AI
Disk 60 MB 1.5 GB with one model downloaded
