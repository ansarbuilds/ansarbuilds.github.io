Under the hood

Privacy and security

Hermione has no account, no analytics and no tracking. Your projects live in a folder on your Mac. This page lists everything that can leave it, and how the app is built so it can't do more than that.

#What leaves your Mac

The same table is in the app under Settings → Privacy.

What When Goes to What's sent
Your projects, issues and pages Never Nowhere Nothing
The assistant (⌘J) Never, with the built-in engine or Hermione AI Runs on this Mac Nothing
Web answers (Pro, if you turn them on) When you ask something that needs the web Your SearXNG server or Brave Search, then the pages it reads The search words and page addresses, never project data
Model download (Pro) When you click Download, and a daily check for new models GitHub and Hugging Face A normal file download
Spotlight While Show in Spotlight is on The Spotlight index on this Mac Keys, titles and the start of descriptions; nothing leaves the Mac
Update check When you choose Check for Updates GitHub The app version
Diagnostics Only when you copy and paste them Wherever you paste them Versions, counts, the error log; no project text
Your own model server If you set one up The address you chose, usually this Mac Your request and project context
Sync Only if you turn it on (not available yet) Your devices, and the relay you chose Changes encrypted on your device

#How the app is locked down

  • The window can do very little. The Mac app's windows get only Tauri's core permissions: no shell, no general file access, no arbitrary network. Each thing the interface needs (save, read an attachment, start the model) is one narrowly checked Rust command.
  • A strict content policy. Scripts load only from the app itself; there is no remote code. Web links open in your browser, not in Hermione's window.
  • Markdown never becomes HTML. Pages and comments are parsed into interface elements, so a page can't run a script.
  • Names and paths are checked. Store names can't contain .. or slashes, attachment ids are plain characters, downloads take a plain file name, and moving the data folder compares real, resolved paths.
  • The web tools can't reach your network. Pages are read over https only. Local names, .local, and private, loopback and link-local addresses are refused, and the address is checked after it's looked up, so a public name that points inside your network is refused too.
  • Private pages stay private. A private page is filtered out before any view, search, backlink or export sees it.

The full review, with what's still open, is in docs/security-review.md.

#Models and licences are signed

  • The list of models is signed with Ed25519 using a key that is kept offline, never on a build machine. The app checks the signature against public keys built into it; an unsigned or altered list is refused.
  • Each model file is checked against the SHA-256 in that signed list before it loads. A mismatch deletes the file.
  • Pro licence keys are signed the same way and checked on your Mac, with no account and no network call.

#Reporting a problem

Please report security issues privately, as described in SECURITY.md, not in a public issue.
