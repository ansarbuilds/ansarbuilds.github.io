The assistant

The assistant

Press ⌘J (or the sparkle button, bottom right) and type what you want, the way you'd tell a teammate. Hermione makes the change and tells you what it did, with Undo under every answer.

It works offline, out of the box. Nothing you type is sent anywhere unless you turn on web answers, and even then only the search words go.

#What you can ask

Say It does
create a bug: export button does nothing, high priority, for @noah due friday One issue with the type, priority, assignee and due date set
move HER-5 to done and assign HER-2 to me Two changes, one Undo
make it urgent (with an issue open) "it" and "this" mean the issue on screen
plan the next sprint with 20 points Fills the next sprint from the top of the backlog until 20 points
start the next sprint · complete the sprint, move the rest to the backlog Runs the sprint; completing asks first
what's assigned to me? · overdue bugs Lists matching issues
how is the sprint going? A summary: points done, what's late, what's at risk
catch me up on HER-3 · what happened this week? The changes and comments since, in a few lines
draft a retro for the last sprint · draft release notes · write a status update A new page written from the project's real data
write a page called Release checklist A new page
comment on HER-4: shipped in 0.3 A comment
archive HER-7 and HER-8 Archives them, after asking
switch to dark mode · make the text bigger · use violet Changes the app
go to the roadmap · open HER-12 Takes you there

Corrections work too: after "move HER-2 to review", "oops, I meant in progress" fixes it.

#Plans before big changes

When one request would change more than five things, or a model proposes more than one change, Hermione shows the plan first: every step in words, each with a tick box. Untick what you don't want, then Apply, or Cancel.

Some things always ask first, whatever their size: archiving issues and completing a sprint. One request can never change more than 25 things.

#Undo

Every answer that changed something has Undo this (or Undo these 6 changes), and everything the assistant does also goes into the normal undo history (⌘Z, ⇧⌘H) and each issue's History. Fields the assistant set carry a small mark with the sentence that set them.

#How it understands you

The assistant has two engines, and uses them in order.

  1. The built-in engine reads common sentences with hand-written rules: issue keys, statuses by meaning ("finished", "shipped", "wip"), priorities ("p1", "urgent", "blocker"), people ("me", "@noah", "Priya"), dates ("friday", "end of the week", "in 3 days", "dec 3"), points, labels and sprints. It answers in milliseconds, offline, with no model at all. This is what you get by default.
  2. A model, if one is set up, for anything the engine can't place: vague requests, long sentences with several things in them, questions. It sees the same tools and a short description of the project, and answers with tool calls. Choose one in Settings → Assistant:
    • Hermione AI (Pro): Hermione's own model, trained for exactly these tools, downloaded once and run on your Mac. See Hermione AI models.
    • Your own model: any OpenAI-compatible server, such as llama.cpp, Ollama, LM Studio or vLLM, usually on your Mac.

Whichever engine answers, the same checks run before anything changes: the workflow's rules, the limits above, and confirmation for archive and complete.

#Every tool

The assistant can do exactly these things and nothing else. The list is one file in the code (packages/core/src/assistant/tools.ts); the built-in engine, the model and the training data all use it.

Tool Kind Does
navigate view Opens a view (home, board, backlog, issues, sprints, roadmap, releases, pages, inbox, settings) or an issue
set_theme view Light, dark, or follow the system
set_accent view The accent colour
set_density view Compact or comfortable
set_text_size view Small, normal, large, larger
toggle_sidebar view Collapses or expands the sidebar
search_issues read Finds issues by text, status, assignee, priority, type, or overdue
summarize read The state of the sprint, your work, or the project
catch_up read What changed lately on one issue or the whole project
create_issue change One issue with any of its fields, parent and description
update_issues change Changes fields on one or more issues by key: status, assignee, priority, points, due date, type, sprint, labels, summary
comment change Adds a comment
create_sprint change Plans a new sprint, with a goal and a length
plan_sprint change Fills a sprint by keys, or by priority up to a points budget
start_sprint change Starts the next planned sprint
complete_sprint change, asks first Completes the active sprint, sending unfinished work to the backlog or the next sprint
create_page change Writes a new page, optionally under another
draft change Writes a retro, release notes or a status update from the project's real data
archive_issues change, asks first Archives issues (they can be restored)
web_search web Hermione AI + Web only: searches the web
read_web_page web Hermione AI + Web only: reads a page it found

#Web answers

With Hermione AI + Web (Pro) and web answers on, you can ask about things outside your project: "what changed in React 19.3?", "what's the Postgres default for max_connections?". The model decides what to search for; the app runs the search on your own SearXNG server or Brave Search, reads up to a few pages, and the model answers on your Mac, naming its sources.

What leaves your Mac: the search words and the addresses of the pages it reads. Never your project. The model is trained never to put project details in a search, and only https:// pages on the public internet are read; local and private network addresses are refused.

#Teach it your way of working

Turn on Keep examples to improve the model in Settings → Assistant and the requests the assistant got right (the ones you kept, where every step worked) are saved on your Mac in the same format as the training data. Under Recent actions, download them as hermione-training.jsonl, ready for training your own model.

#When it doesn't understand

It says so, with examples of what it can do. Rephrase with an issue key and a plain verb ("move HER-3 to done"), or set up Hermione AI or your own model for looser language.
